THEORY
Frequency is the number of waves passing an area per unit second. For a periodic wave, frequency is the rate at which the disturbance is repeated. Fundamental frequency is the lowest frequency corresponding to n=1. The fundamental frequency is produced by the first harmonic. The fundamental wave pattern is a transverse standing wave pattern. A standing wave does not travel in one direction or the other as do the individual. The fundamental frequency is produced by plucking the string gently in the middle which sets up the simplest stationary wave. A displacement node is obtained at each ends of the string because these points cannot move, and displacement antinodes are obtained in the middle where the string is most free to move. Nodes are places that do not vibrate at all and antinodes are places of maximum vibrations. METHOD
The string was laid across two triangular sliders and clamped between a fixed hook and a spring balance. The spring balance was attached to a tensioner with fishing line. The string length was set by moving the triangular sliders along the scale to fixed length. The string outside the sliders was prevented from vibrating by laying a figure on it gently. The vibration of the string was optically scanned midway between the sliders. The signal of the photo-cell fitted with an aperture slit was amplified and transmitted to the oscilloscope and the counter/timer. The string was given a gentle tap with the rubber hammer to set it into vibration. The time counter was started when the harmonics have died away.     The length of the wire between the two triangular sliders was set to 60cm and then recorded. The length of the wire was kept constant throughout the experiment. The diameter of the wire was then recorded. Keeping the length of the string constant between the sliders at the recorded value (60cm), the tension T=5N in the string was measured. The counter/timer device was set to frequency (KHz). The sensor was aligned to the string and light so that the counter read zero. The start button was then pressed. The wire was then gently tapped with the rubber hammer to start the vibrations. The stop button was pressed when the harmonics had died away (frequency was stable) and the frequency was recorded. The experiment was repeated for four other values of T= 10, 15, 20,25N. A graph of against  was plotted. The slope of the graph was the determined and also the mass per unit length and the density of the string.

SOURCES OF ERROR
Error might have been caused by the improper calibration of the counter/timer which might have given wrong values for the frequencies measured.
Error might have been caused by the improper calibration of the meter rule that was used to measure the length of the string. The recorded value of the length string (that is 60cm) might not be the actual length.
There might be some parallax error in the measurement of the length of the string. 
It is possible that the calibration of the spring balance and other apparatuses used were not properly calibrated and therefore resulted in errors in one way or the other.
PRECAUTIONS
It was ensured that the tension did not exceed 30N in order to prevent the string from breaking.
The experiment was repeated in order to avoid random error.
The counter/timer was only started when the harmonics had died away in order to record the frequency only when it became stable and to ensure accuracy.
The triangular sliders were well fixed in so that they would not slip in the course of the experiment that was done to eliminate errors.
