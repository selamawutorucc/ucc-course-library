PROCEDURE                                                                                                                                                                               The Constantine wire (string) was laid across two triangular sliders and clamped between a fixed hook and a spring balance. The spring balance was then attached to a string tensioner with a fishing line. The tensioning force was kept at 10N. The string length was set by moving the triangular sliders along the measuring scale. It was ensured that the strings outside the sliders didn’t vibrate by gently touching them any time they vibrate. This was carefully done so that string tension was not altered. The photo-cell was set such that the vibration of the Constantine wire was optically scanned midway between the sliders. The signal from the photo-cell fitted with an aperture slit was amplified and transmitted to the oscilloscope and the counter. The Constantine wire was gently tapped with the rubber hammer to set the string into vibration. The counter was only started once the harmonics had died away.                                The string was set, and the tension in it and its diameter were measured and recorded. The counter device was set to frequency. The sensor was aligned to the string and light so that the counter read zero. Keeping the tension in the string constant, at the recorded value, a string length of l =40cm was measured between the two triangular sliders. The start button was pressed and the wire was gently tapped with the rubber hammer to start the vibrations. The stop button was pressed when the harmonics had died away and the frequency was measured. The experiment was repeated for four other values of l= 50, 60, 70, 80cm.

DISCUSSION
The experiment was done to measure the density of Constantine in a form of a string. The Constantine wire (string) was laid across two triangular sliders and clamped between a fixed hook and a spring balance. With all the precautions put in place, the Constantine wire was gently tapped with the rubber hammer to set the string into vibration. The counter was started once the harmonics had died away and these were the values obtained, at l=40, 50, 60, 70, 80cm the frequencies f, were 0.0705, 0.1365, 0.1135, 0.0975, 0.085kHz respectively. After the experiment,  was found to be 0.036kgm3 and the density of the density of the string was found to be 0.11kg/m3. but comparing this with the actual value which is 8900kg/m3 there is  a big difference in the result. This difference is as result of error. Some of these errors are as follows. There might have been vibrations outside the two sliders which could not have been detected. The string might have not been in line with the sensor due to the frequent adjustments of the length thereby introducing errors in the readings of the frequencies.    
SOURCES OF ERROR 
There might have been vibrations outside the two sliders which could not have been detected.
The string might have not been in line with the sensor due to the frequent adjustments of the length thereby introducing errors in the readings of the frequencies.   
PRECAUTIONS
The experiment was repeated and the average was taken to get accurate results
The sensor and the light were carefully aligned to the string so that the counter read zero before the experiment began. This ensured accurate readings.
CONCLUSION
The density, of the Constantine wire was found to be 0.11kg/m3.
