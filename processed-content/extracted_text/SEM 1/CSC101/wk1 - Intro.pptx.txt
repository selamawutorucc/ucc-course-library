How to command the Computer
User interface
Command Line Interface (CLI)
Text driven
Graphical User Interface (GUI) (or WIMP)
Menu driven
Touchscreen
Voice interface
Programming language
1st Generation – Machine language (1GL)
Uses bits (0/1)
2nd Generation – Assembly language (2GL)
Uses mnemonics (mov, add, mul, etc)
3rd Generation – High level language (3GL)
Natural language (let, if, break, import, return, etc)
Programmer friendly
Machine Independent
Ex: C, C++, C#, Java, BASIC, Pascal, Fortran, ALGOL, COBOL

Characteristics of Computers
Automatic
Mostly require no human involvement during processing of task
Speed
Guarantee fast processing
Microseconds (10-6)
Nanoseconds (10-9)
Picoseconds (10-12)
Accurate
Consistently high
Design dependent
Garbage In Garbage Out (GIGO)
Bad input
Bad programming
Diligent
Guarantee continuity of work
Heat, dust, hacking
