Mail merge
Mail merge is a feature within most data processing applications that enables users to send a similar letter or document to multiple recipients. It enables connecting a single form template with a data source that contains information about the recipient’s name, address and other predefined and supported data

The mail merge process involves the following: 1. The Main Document  2.Data Source
The Main Document – contains the text and graphics that are the same for each version of merge
Data Source – a file that contain the information to be merged into a document. The name and the addressed of the recipients of a letter
