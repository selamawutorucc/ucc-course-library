Mail Merge in word 2010
Mail Merge is feature in Microsoft Word  that allows the user to create multiple e-mails for different recipients at once.

Mail Merge is a feature in MS Word that takes data from a data source and inserts it into a main document containing similar information.

One specific type of information is to be addressed to different individuals  with different addresses.



--- SLIDE 88 ---
Features of Mail Merge in word 2010
Data 
Data is any number or text that is to be used as information. Example: Name, address, Pin code.

Data source
It is the location where data that is used in mail merge is stored. Example a table that contains data from where data is taken and used.

--- SLIDE 89 ---
Features of Mail Merge in word 2010
Main document
It consists of text or information that we wish to send to all the recipients. Example Letter.

Merge Field
It is data item that is to be taken from a data source and inserted into the main document. Example: Name, Address, City, etc. that is to be inserted to the main document.
