Method: 
A nickel wire string was laid across 2 triangular sliders and clamped between a fixed hook and a spring balance. The spring balance was attached to a string tensioner with a fishing line. The string length was set by moving the triangular sliders along the measuring scale. The vibration of the string was optically scanned midway between the sliders. The signal from the photocell, fitted with an aperture slit was amplified and transmitted to the oscilloscope and the counter/ timer.  The tension in the string was set to a fixed value and recorded as 20N. The diameter of the string was also measured and recorded.  Keeping the tension in the string constant at the recorded value, a string length l = 40cm was measured between the two triangular sliders. The counter /timer device was set to frequency (kHz).  The sensor was aligned to the string and light so that the counter read zero and the start button was pressed. The wire was gently tapped with the rubber hammer to start the vibrations. The stop button was pressed when the harmonics had died away and frequency became stable. This frequency was then recorded. This was repeated for four other values of l=50, 60, 70, 80 cm

Discussion: 
From the experiment, it was observed that the frequency was inversely proportional to the length. This can be seen from the table of results.  The smallest length of 40cm, yielded the highest frequency of 0.2110kHz . The greatest length of 80 cm likewise yielded the smallest frequency of 0.1065kHz.  The density of the string was found to be 9.85×10-3 kg/m3 .The literature density of nickel is 8900 kg/m3 . This great difference may be due to distortion in the shape or bends in the string leading to a change in volume. This affected the accuracy of the experiment.
Precautions:
It was ensured that the tensioning force was not set beyond 30N in order to prevent the string from breaking
The experiment was repeated and the average frequency found to ensure accurate results.
It was ensured that throughout the experiments the tension was kept constant
Sources of error:
The frequencies were hardly stable hence making readings difficult 
Error due to the non uniformity of the string hence affecting the mass per unit length
