THEORY
Standing waves arise because identical waves (equal frequency, velocity and amplitude) travel on a string in opposite directions in the same medium and combine in accord with the principle of superposition on each other. Consider a string that has length L and is fixed at both ends. The string has numerous natural patterns of vibration known as normal modes and each of these has a characteristic frequency. The normal modes form a harmonic series. The first harmonic with the lowest frequency is called the fundamental note and its frequency is referred to as the fundamental frequency. The second harmonic is also known as the first overtone.

METHOD
A nickel wire string was laid across 2 triangular sliders and clamped between a fixed hook and a spring balance. The spring balance was attached to a string tensioner with a fishing line. The string length was set by moving the triangular sliders along the measuring scale. The vibration of the string was optically scanned midway between the sliders. The signal from the photocell, fitted with an aperture slit was amplified and transmitted to the oscilloscope and the counter/ timer.  The tension in the string was set to a fixed value and recorded as 10N. The diameter of the string was also measured and recorded.  Keeping the tension in the string constant at the recorded value, a string length l = 40cm was measured between the two triangular sliders. The counter /timer device was set to frequency (kHz).  The sensor was aligned to the string and light so that the counter read zero and the start button was pressed. The wire was gently tapped with the rubber hammer to start the vibrations. The stop button was pressed when the harmonics had died away and frequency became stable. This frequency was then recorded. This was repeated for four other values of l=50, 60, 70, 80 cm

DISCUSSION
	From the experiment, it was observed that the frequency was inversely proportional to the length. This can be seen from the table of results.  The smallest length of 40cm yielded the highest frequency of 175 Hz. The greatest length of 80 cm likewise yielded the smallest frequency of 89 Hz.  The density of the string was found to be 7.27×103 kg/m3 .The literature density of nickel is 8900 kg/m3. The difference in the experimental value and the literature value may be due to distortion in the shape or bends in the string leading to a change in volume. This affected the accuracy of the experiment.
SOURCES OF ERROR
The frequencies were hardly stable hence making readings difficult 
Error due to the non uniformity of the string hence affecting the mass per unit length
PRECAUTIONS
It was ensured that the tensioning force was not set beyond 30N in order to prevent the string from breaking
The experiment was repeated and the average frequency found to ensure accurate results.
It was ensured that throughout the experiments the tension was kept constant
CONCLUSION
The slope of the graph was 69.57Hz/m at fixed tension, T = 10N. Mass per unit length µ is                5.17 x10-4kg/m and density of the string, d is 7.27 x 10-3kg/m3. It can be concluded that the frequency is inversely proportional to the length of the string.
